## 🛠 Lerax Chain

Lerax Chain is a **modular and extensible framework** for building Ethereum-compatible blockchain networks.

It is an **independent fork of Polygon Edge**, adapted and optimized for:

- **Tokenization of Real-World Assets (RWA)**
- **Proof of Authority (PoA)** consensus for predictable governance
- **Seamless integration** with the Lerax ecosystem
- **Enterprise-ready** security and scalability

With Lerax Chain, you get the best of Polygon Edge’s architecture combined with new capabilities designed to power the next wave of Web3 adoption.
